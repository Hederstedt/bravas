# Bravas (BVS)

Klansida för BVS — ett gäng goa gubbar från Västra Götaland som lirar CS2, Valheim och Satisfactory.

Byggd med React + Vite + TypeScript. CI, CodeQL-skanning och Dependabot körs via GitHub Actions.
